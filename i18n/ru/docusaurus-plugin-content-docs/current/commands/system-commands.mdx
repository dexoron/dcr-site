# Системные команды

## `dcr setup`

Инициализирует окружение DCR.

```bash
dcr setup
```

Создаёт:
- `~/.dcr/config.toml` — конфигурация реестров
- `~/.dcr/index.json` — индекс пакетов публичного реестра

После `setup` можно сразу добавлять зависимости из реестра.

```bash
dcr setup --show    # показать текущие реестры
```

## `dcr --help`

Показывает справку по всем командам и флагам.

```bash
dcr --help
dcr build --help    # справка по конкретной команде
```

## `dcr --version`

Показывает версию.

```bash
dcr --version       # dcr 0.7.0
```

## `dcr --update`

Самообновление. Скачивает последний релиз с GitHub Releases и заменяет текущий бинарник.

```bash
dcr --update
```

Особенности:
- Определяет платформу и архитектуру автоматически
- Если DCR установлен через AUR, выводит предупреждение (используйте `yay -S dcr`)
- Работает на Linux, macOS, Windows
