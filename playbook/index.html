DCR vs Alternatives

Choose the right tool by task and complexity.

Tool Best For Notes
DCR Small/medium C/C++ projects with fast CLI workflow Minimal setup, Cargo-like commands, dcr.toml
Make Very custom build pipelines Flexible but harder to maintain as complexity grows
CMake Large cross-platform and IDE-heavy environments Powerful ecosystem, steeper learning curve
Meson Teams that prefer declarative build configs Readable files and good defaults, smaller ecosystem

Quick Start in 60 Seconds

Install DCR, create a project, and run it.

1. Install

Use the install script in your shell.

curl -fsSL https://dcr.dexoron.su/install.sh | bash

2. Create

Scaffold a new project.

dcr new hello

3. Run

Build and launch your app.

cd hello
dcr run
