DCR и альтернативы

Выберите инструмент под масштаб и задачи проекта.

Инструмент Лучше всего для Комментарий
DCR Небольших/средних C/C++ проектов с быстрым CLI workflow Минимальная настройка, команды в стиле Cargo, dcr.toml
Make Очень кастомных пайплайнов сборки Гибко, но сложнее поддерживать при росте проекта
CMake Крупных кроссплатформенных проектов и IDE-интеграции Мощная экосистема, выше порог входа
Meson Команд, которым важны декларативные конфиги Понятные файлы и хорошие дефолты, но экосистема меньше

Быстрый старт за 60 секунд

Установите DCR, создайте проект и запустите его.

1. Установка

Выполните установочный скрипт в терминале.

curl -fsSL https://dcr.dexoron.su/install.sh | bash

2. Создание

Сгенерируйте новый проект.

dcr new hello

3. Запуск

Соберите и запустите приложение.

cd hello
dcr run
