# DCR — инструмент сборки C/C++ и менеджер пакетов

DCR — инструмент сборки и менеджер пакетов для проектов на C и C++. Он поддерживает инкрементальную и параллельную сборку, зависимости, кросс-компиляцию и несколько компиляторов.

Быстрый способ начать — установить `dcrup`, а затем поставить стабильную версию DCR.

<details>
<summary>Краткая справка</summary>

```bash
# Установка dcrup
curl -fsSL https://sh.dcr-tool.ru | sh -s -- self-install
export PATH="$HOME/.dcr/bin:$PATH"
dcrup install stable

# Создание проекта
dcr new my-app
cd my-app

# Сборка и запуск
dcr build
dcr run

# Запуск тестов
dcr test

# Добавление зависимости
dcr add fmt

# Генерация файлов для IDE
dcr gen vscode
```

</details>

## Возможности

- **Инкрементальная сборка** — отслеживание времени изменения, заголовков через `.d` и SHA-256-отпечатка.
- **Параллельная компиляция** — обработка задач несколькими потоками.
- **Несколько бэкендов** — GCC, Clang, MSVC, clang-cl, GAS, NASM, MASM, FASM и LLVM IR.
- **Разные типы проектов** — приложения, статические и динамические библиотеки, EFI, ELF и другие варианты.
- **Кросс-компиляция** — короткие имена целевых платформ и полные target triples.
- **Профили сборки** — `debug` и `release` с переопределением параметров.
- **Рабочие пространства** — сборка нескольких пакетов с учётом зависимостей между ними.
- **Зависимости** — из реестра, Git-репозитория или локального пути.
- **Генерация файлов IDE** — для VS Code, CLion, `compile_commands.json` и JSON-метаданных.
- **Справка по командам** — например, `dcr build --help` и `dcr new --help`.
